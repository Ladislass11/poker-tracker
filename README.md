# Poker Tracker для Majestic

Программа для покера на сервере Majestic RP (Windows, Python).

- **Трекер раздач:** сама делает снимки экрана, распознаёт ваши карты и карты стола, пишет каждую раздачу в `hands.csv` и строит отчёт: совпадает ли статистика раздачи с теорией вероятностей.
- **Подсказки поверх игры:** окошко с советом (чек / колл / фолд / ставка / рейз / ол-ин), шансами выиграть, вашей рукой, позицией (по значку D) и стеком в блайндах.
- **Профили соперников:** запоминает игроков по номеру (#12345) в `players.json`: сколько рук играют, агрессия, фолд на ставку, показанные карты.

## Запуск
1. Установите Python 3.10+.
2. `1_install.bat` - библиотеки.
3. Игра в режиме «Оконный без рамки», затем `2_check.bat` - проверка распознавания (`check.png`).
4. `3_start_tracker.bat` - только запись раздач, `5_start_with_hints.bat` - запись + подсказки.
5. `4_report.bat` - отчёт по статистике.

Подробно - в `README.txt`.

## Файлы
| Файл | Что делает |
|---|---|
| `poker_tracker.py` | распознавание карт, запись раздач, отчёт |
| `hints.py` | суммы на кнопках и в банке, шансы (Монте-Карло), советы |
| `players.py` | панели игроков (ID, стек, действие), значок D, позиция, профили |
| `overlay.py` | окно-подсказка поверх игры |
| `templates.npz` | эталоны карт, цифр и надписей |

`hands.csv`, `players.json` и `report.txt` создаются при игре и в репозиторий не попадают (`.gitignore`).
